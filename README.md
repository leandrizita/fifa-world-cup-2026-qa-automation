# fifa-world-cup-2026-qa-automation
Um projeto voltado para demonstração de habilidades em QA, automação de testes, APIs, testes de dados e geração de relatórios utilizando informações dos jogos da FIFA World Cup 2026.

Objetivo

Criar uma suíte completa de testes automatizados para validar dados da Copa do Mundo de 2026, simulando um cenário real de QA em aplicações esportivas.

O projeto pode demonstrar conhecimentos em:

Automação Web
Testes de API
Testes de Contrato
Validação de Dados
BDD
CI/CD
Relatórios
Boas práticas (Page Object, Factory, Fixtures)
